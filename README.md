# RepoScout

Find open-source projects to contribute to through gamified repository matching.

**Live Demo**: https://repo-scout-nine.vercel.app/

[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

---

## Features

- **Gamification System** - XP, levels, quests, achievements, leaderboards
- **Smart Matching** - Repository matching based on skills and interests
- **Analytics Dashboard** - Contribution tracking with heatmaps and charts
- **Repository Explorer** - Search and filter repositories
- **Issue Browser** - Find good first issues
- **Swipe Discovery** - Tinder-style repository browsing

---

## Quick Start

```bash
git clone https://github.com/pallaviXD/RepoScout.git
cd RepoScout
npm install
npm run dev
```

Open http://localhost:3000 - works instantly, no configuration needed.

## Deployment

Deploy to Vercel with one click:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/pallaviXD/RepoScout)

Or use Vercel CLI:

```bash
npm install -g vercel
vercel --prod
```

No environment variables required for demo mode.
