# RepoScout - Frontend Demo Mode

## 🎯 Overview

This is a **frontend-only demo** version of RepoScout created for project submission. The focus is on showcasing the UI/UX design and user experience without requiring backend authentication or database setup.

## ✨ What's Working

### Pages & Features
- ✅ **Landing Page** - Beautiful video background hero section
- ✅ **Explore** - Browse repositories with live GitHub API
- ✅ **Issues** - Search and filter open-source issues  
- ✅ **Good First Issues** - Beginner-friendly contribution opportunities
- ✅ **Dashboard** - Personalized feed with horizontal scrolling cards
- ✅ **Analytics** - Contribution tracking visualization
- ✅ **Repository Details** - Individual project pages

### UI Components
- ✅ Responsive navigation with smooth transitions
- ✅ Horizontal scrolling card layouts
- ✅ Match score badges and difficulty indicators
- ✅ Issue cards with labels and metadata
- ✅ Repository cards with language indicators
- ✅ Search functionality

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open browser
http://localhost:3000
```

## 🎨 Design Highlights

1. **Video Background Hero** - Immersive landing page with mux video streaming
2. **Dark Theme** - Professional black & white aesthetic
3. **Smooth Animations** - Cubic-bezier transitions throughout
4. **Horizontal Scrolling** - Modern card-based layouts in dashboard
5. **Responsive Design** - Works on desktop, tablet, and mobile
